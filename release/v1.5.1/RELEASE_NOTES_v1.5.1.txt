BG Gremlin APK Recovery 1.5.1 is the rebuild-oriented Android release.

The application is portrait-only. Its primary export is no longer a report-only preservation bundle. It creates a dedicated recovery workspace per APK, preserves the entire APK payload, exports exact DEX code-item evidence even when identifiers are obfuscated, separates source/framework/native/obfuscation evidence, creates machine-readable inventories, and can export the complete workspace as a portable ZIP.

The per-project working folder is stored under BGGremlinAPKRecovery/Output/<apk-name>_<sha12>/ in app-private storage. This avoids requesting broad Android filesystem permissions. Export Project ZIP uses the Android save flow for a portable external copy; content:// destinations are staged internally and copied through FileAccess.

The signed APK is suitable for clean installation. Because the original 1.5.0 private signing key was not supplied, use the aligned unsigned APK with that original key when Android update-signature continuity is required.
